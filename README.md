# J-ROC Universal Phone Repair Suite

Standalone React + TypeScript + Vite web application foundation.

## Scope
- Repair job intake and tracking
- Customer/device records
- Major-brand device profiles
- Browser-safe diagnostics workspace
- Authorized recovery workflow tracking
- Carrier-unlock eligibility tracking
- Audit-safe repair workflow foundation

## Safety
This project does not defeat FRP, Activation Lock, screen locks, passwords, or other anti-theft controls. Recovery flows are for documented authorization and manufacturer/carrier-supported procedures.

## Run
Install Node.js 20+ or newer, then run `npm install` and `npm run dev`.

## Windows Desktop Edition — V20.0.0
This project now includes an Electron desktop shell and a GitHub Actions Windows packaging workflow. The intended installer output is `J-ROC-Universal-Repair-Suite-PRO-V20.0.0-Setup.exe`.

The installer is only considered release-ready after a successful Windows CI build and artifact verification. The source package itself does not contain a precompiled `.exe`.
